## Coming Soon

The Cozmo CLI is currently in development. It will allow you to manage agents, sessions, calls, and workflows directly from your terminal - including live webhook forwarding to your local server for development.

## Planned features

- **Agent management** - create, list, update, and delete agents from the terminal
- **Workflow runs** - trigger workflow runs for individual prospects without writing code
- **Webhook forwarding** - forward live `call.completed` and `session.completed` events to your local server for development and testing
- **Project scaffolding** - `cozmo init` to generate integration boilerplate for your stack
- **MCP setup** - one-command IDE configuration for Cursor, Claude Code, Windsurf, and VSCode
