## Overview

This guide walks through the complete flow for placing an AI voice call with Nova:

1. Create a voice agent
2. Configure the agent (LLM, voice, transcriber)
3. Find your workflow
4. Trigger a workflow run for a prospect
5. Monitor via webhook
6. Inspect the call record

By the end you will have a fully working integration that places calls, captures results, and feeds data back to your system.

## Prerequisites

Before starting, make sure you have:

- A Cozmo AI account with an active organization
- An API key from [Dashboard - Organization Settings](https://dash.prod.czmx.in)
- A phone number provisioned in your organization (configured in the Dashboard)
- A workflow created in the Dashboard with `trigger_type: api`
- Your `org_id` (shown in the Dashboard and in the URL of every Dashboard page)

<Info>
  Your `org_id` is a UUID that scopes all API resources. It appears in Dashboard URLs as `dash.prod.czmx.in/org/YOUR_ORG_ID/...`.
</Info>

## Step 1 - Create a voice agent

An agent defines how your AI behaves on the call - its personality, goals, and response style. Create one via the API or the Dashboard.

<CodeGroup>

```bash cURL
curl -X POST https://v2-nova-api.prod.czmx.in/api/org/{org_id}/agents \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Outbound Sales Agent",
    "type": "voice",
    "prompt_template": "You are a friendly outbound sales agent for Acme Corp. Your goal is to reconnect with prospects who requested a demo and schedule a follow-up meeting. The prospect'\''s name is {{prospect_name}}. Be concise and respectful of their time. If they ask to be removed from the list, always honor the request immediately."
  }'
```

### Scheduling calls for a future time

Pass `scheduled_at` to queue the call for a specific time rather than triggering immediately:

```json
{
  "workflow_id": "wf_abc123",
  "scheduled_at": "2026-04-22T14:00:00Z",
  "prospect": {
    "phone": "+19175551234",
    "first_name": "Jane"
  }
}
```

<Info>
  Use UTC in `scheduled_at`. If your workflow is configured with local calling hours, Nova will also respect those constraints - the call fires at whichever time comes later.
</Info>

## Step 5 - Monitor via webhook

Set up a webhook endpoint to receive real-time notifications when calls complete or fail. This is far more efficient than polling.

<Tabs>
  <Tab title="Node.js (Express)">
    ```typescript TypeScript
    import express from "express";
    import crypto from "crypto";

    const app = express();
    app.use(express.json());

    const NOVA_WEBHOOK_SECRET = process.env.NOVA_WEBHOOK_SECRET!;

    app.post("/webhook/cozmo", async (req, res) => {
      // Return 200 immediately - process in background
      res.json({ ok: true });

      const { event, data } = req.body;

      try {
        switch (event) {
          case "call.completed":
            await handleCallCompleted(data);
            break;
          case "call.failed":
            await handleCallFailed(data);
            break;
          case "session.completed":
            await handleSessionCompleted(data);
            break;
        }
      } catch (err) {
        console.error("Webhook processing error", { event, error: err });
      }
    });

    async function handleCallCompleted(data: any) {
      const {
        call_id,
        call_result,
        summary,
        transcript,
        recording_url,
        prospect,
        evaluations,
        dnc_requested,
        sentiment,
      } = data;

      console.log("Call completed", { call_id, call_result, sentiment });

      // Handle DNC immediately
      if (dnc_requested) {
        await addToDncList(prospect.ID, prospect.ExternalId);
        return;
      }

      // Read evaluations
      const evalMap = Object.fromEntries(
        (evaluations ?? []).map((e: any) => [e.key, e])
      );

      if (evalMap.INTERESTED?.result_boolean) {
        // Prospect is interested - update CRM
        await updateCrm(prospect.ExternalId, {
          status: "interested",
          summary,
          recording_url,
          call_id,
        });
      }

      if (evalMap.CALLBACK_REQUESTED?.result_boolean) {
        await scheduleCallback(prospect.ExternalId, call_id);
      }
    }

    async function handleCallFailed(data: any) {
      const { call_id, call_result, prospect } = data;
      console.warn("Call failed", { call_id, call_result, prospect_id: prospect?.ID });

      if (call_result === "NO_ANSWER") {
        // Schedule retry for 4 hours later
        await scheduleRetry(prospect.ExternalId, 4 * 60 * 60 * 1000);
      }
    }

    async function handleSessionCompleted(data: any) {
      console.log("Session completed", { session_id: data.session_id, status: data.status });
    }

    app.listen(3000, () => console.log("Webhook listener on :3000"));
    ```
  </Tab>
  <Tab title="Python (FastAPI)">
    ```python Python
    from fastapi import FastAPI, BackgroundTasks, Request
    import logging

    app = FastAPI()
    log = logging.getLogger(__name__)

    @app.post("/webhook/cozmo")
    async def receive_webhook(request: Request, background: BackgroundTasks):
        payload = await request.json()
        # Return 200 immediately, process async
        background.add_task(process_event, payload)
        return {"ok": True}

    async def process_event(payload: dict):
        event = payload.get("event")
        data = payload.get("data", {})

        try:
            if event == "call.completed":
                await on_call_completed(data)
            elif event == "call.failed":
                await on_call_failed(data)
            elif event == "session.completed":
                await on_session_completed(data)
        except Exception as e:
            log.error("webhook_processing_error", extra={
                "event": event,
                "error": str(e),
                "call_id": data.get("call_id"),
            })

    async def on_call_completed(data: dict):
        call_id = data["call_id"]
        call_result = data["call_result"]
        prospect = data.get("prospect", {})
        evaluations = {e["key"]: e for e in data.get("evaluations", [])}

        log.info("call_completed", extra={
            "call_id": call_id,
            "result": call_result,
            "sentiment": data.get("sentiment"),
        })

        # Handle DNC first
        if data.get("dnc_requested"):
            await add_to_dnc(prospect.get("ID"), prospect.get("ExternalId"))
            return

        # Act on evaluations
        if evaluations.get("INTERESTED", {}).get("result_boolean"):
            await update_crm(
                external_id=prospect.get("ExternalId"),
                status="interested",
                summary=data.get("summary"),
                recording_url=data.get("recording_url"),
            )

    async def on_call_failed(data: dict):
        call_result = data.get("call_result")
        prospect = data.get("prospect", {})
        log.warning("call_failed", extra={
            "call_id": data.get("call_id"),
            "result": call_result,
            "prospect_id": prospect.get("ID"),
        })

        if call_result == "NO_ANSWER":
            await schedule_retry(prospect.get("ExternalId"), delay_hours=4)

    async def on_session_completed(data: dict):
        log.info("session_completed", extra={
            "session_id": data.get("session_id"),
            "status": data.get("status"),
            "duration_seconds": data.get("duration_seconds"),
        })
    ```

## Handling failures

Not every call succeeds. Handle each failure type appropriately:

| call_result | When it happens | What to do |
|-------------|-----------------|------------|
| `NO_ANSWER` | Prospect didn't pick up | Retry at a different time; respect local calling hours |
| `BUSY` | Line was busy | Retry after 15-60 minutes |
| `FAILED` | Technical error during the call | Retry after a 5-minute delay |
| `FAILED_SIP` | Carrier-level error | Check SIP configuration; contact support if persistent |
| `FAILED_VALIDATION` | Agent or prospect config invalid | Inspect configuration; do not auto-retry |
| `CANCELLED` | Call cancelled before connecting | Investigate; may be intentional |

```python Python
async def on_call_failed(data: dict):
    result = data.get("call_result")
    prospect_external_id = data["prospect"]["ExternalId"]

    retry_delays = {
        "NO_ANSWER": 4 * 3600,     # 4 hours
        "BUSY": 3600,               # 1 hour
        "FAILED": 300,              # 5 minutes
        "FAILED_SIP": 1800,         # 30 minutes
    }

    delay = retry_delays.get(result)
    if delay:
        await schedule_retry_run(
            workflow_id="wf_abc123",
            prospect_external_id=prospect_external_id,
            delay_seconds=delay,
        )
    elif result == "FAILED_VALIDATION":
        # Alert on-call - this needs a human to investigate
        await alert_oncall(f"FAILED_VALIDATION for prospect {prospect_external_id}")
```

## What to do after the call - CRM update pattern

def update_crm_from_call(call_data: dict):

    external_id = prospect["ExternalId"]
    evaluations = {e["key"]: e for e in call_data.get("evaluations", [])}

    crm_update = {
        "last_call_id": call_data["call_id"],
        "last_call_at": "now",
        "call_summary": call_data.get("summary"),
        "recording_url": call_data.get("recording_url"),

    # Map evaluation outcomes to CRM fields
    if evaluations.get("INTERESTED", {}).get("result_boolean"):
        crm_update["lead_status"] = "hot"
        crm_update["next_action"] = "schedule_demo"

    elif evaluations.get("CALLBACK_REQUESTED", {}).get("result_boolean"):
        crm_update["lead_status"] = "warm"
        crm_update["next_action"] = "schedule_callback"

    elif evaluations.get("NOT_INTERESTED", {}).get("result_boolean"):
        crm_update["lead_status"] = "cold"
        crm_update["next_action"] = "archive"

    crm.update_contact(external_id, crm_update)

## Complete end-to-end production example

This script orchestrates the full flow in one place - useful for testing and as a reference for production integrations:

```python Python
"""
Complete Nova API integration example.
Run with: NOVA_API_KEY=your_key ORG_ID=your_org python example.py
"""
import os
import uuid
import time
import logging
import requests

logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")
log = logging.getLogger(__name__)

BASE_URL = "https://v2-nova-api.prod.czmx.in/api"
ORG_ID = os.environ["ORG_ID"]
API_KEY = os.environ["NOVA_API_KEY"]
HEADERS = {"X-API-Key": API_KEY, "Content-Type": "application/json"}


def api(method: str, path: str, **kwargs) -> dict:
    """Make an API call with error handling."""
    url = f"{BASE_URL}/org/{ORG_ID}{path}"
    response = requests.request(method, url, headers=HEADERS, timeout=30, **kwargs)
    if not response.ok:
        body = response.json() if response.content else {}
        raise Exception(f"Nova API {response.status_code}: {body.get('message', 'unknown error')}")
    return response.json()


def create_agent() -> str:
    log.info("Creating voice agent...")
    agent = api("POST", "/agents", json={
        "name": "Demo Sales Agent",
        "type": "voice",
        "prompt_template": (
            "You are a friendly sales agent for Acme Corp. "
            "Follow up with {{prospect_name}} about their demo request."
        ),
    })
    agent_id = agent["id"]
    log.info(f"Created agent: {agent_id}")

    # Configure LLM, voice, transcriber
    api("PUT", f"/agents/{agent_id}", json={
        "llm_config": {"provider": "openai", "model": "gpt-4o", "temperature": 0.7},
        "transcriber_config": {"provider": "deepgram", "model": "nova-3", "language": "en-US"},
        "voice_config": {"provider": "elevenlabs", "voice_id": "21m00Tcm4TlvDq8ikWAM"},
        "greeting_config": {
            "agent_speaks_first": True,
            "greeting": "Hi {{prospect_name}}, this is Alex from Acme Corp!",
        },
    })
    log.info(f"Agent {agent_id} configured")
    return agent_id


def find_workflow(name_contains: str = "") -> str:
    log.info("Finding API-triggered workflow...")
    data = api("GET", "/workflows", **{"params": {"is_active": True, "trigger_type": "api"}})
    workflows = data["data"]
    if not workflows:
        raise Exception("No active API-triggered workflows found")

    wf = next((w for w in workflows if name_contains.lower() in w["name"].lower()), workflows[0])
    log.info(f"Using workflow: {wf['id']} - {wf['name']}")
    return wf["id"]


def trigger_run(workflow_id: str, prospect: dict, scheduled_at: str = None) -> str:
    log.info(f"Triggering workflow run for {prospect['phone']}...")
    body = {"workflow_id": workflow_id, "prospect": prospect}
    if scheduled_at:
        body["scheduled_at"] = scheduled_at

    result = api("POST", "/workflow-runs", json=body)
    run_id = result["workflow_run_id"]
    log.info(f"Created workflow run: {run_id}")
    return run_id


def get_call(call_id: str) -> dict:
    return api("GET", f"/calls/{call_id}")


def poll_for_session(run_id: str, timeout_seconds: int = 300) -> str:
    """Poll sessions until we find one for this run (webhook is preferred in production)."""
    log.info(f"Polling for session associated with run {run_id}...")
    deadline = time.time() + timeout_seconds
    while time.time() < deadline:
        sessions = api("GET", "/agent-sessions", params={"page": 1, "size": 10})
        for session in sessions.get("data", []):
            # In production, match via workflow_run_id field
            if session.get("status") in ("COMPLETED", "STOPPED", "FAILED", "CANCELLED"):
                log.info(f"Found completed session: {session['id']}")
                return session["id"]
        time.sleep(10)
    raise TimeoutError(f"No completed session found within {timeout_seconds}s")


def main():
    # Step 1 - Create and configure agent
    agent_id = create_agent()

    # Step 2 - Find workflow
    workflow_id = find_workflow()

    # Step 3 - Trigger a run
    prospect = {
        "phone": "+19175551234",
        "first_name": "Jane",
        "last_name": "Doe",
        "email": "jane.doe@example.com",
        "external_id": f"demo_{uuid.uuid4().hex[:8]}",
        "custom_data": {
            "demo_requested_at": "2026-04-15",
            "product_interest": "Enterprise Plan",
            "company": "Acme Corp",
        },
    }
    run_id = trigger_run(workflow_id, prospect)

    log.info("Call queued. In production, use webhooks to receive completion events.")
    log.info(f"Workflow run ID: {run_id}")
    log.info("Configure your webhook at: https://dash.prod.czmx.in")


if __name__ == "__main__":
    main()
```

## Best practices for production calls

<CardGroup cols={2}>
  <Card title="Always pass external_id" icon="fingerprint">
    Set `external_id` to your CRM contact ID. Nova deduplicates prospects on this field, so re-triggering a workflow for the same contact does not create duplicate records.
  </Card>
  <Card title="Use custom_data for agent context" icon="database">
    Pass relevant prospect context in `custom_data` - deal stage, product interest, previous interactions. The agent can reference this during the call through the prompt template.
  </Card>
  <Card title="Webhooks over polling" icon="webhook">
    Use webhook events rather than polling the API. Webhooks are real-time, reduce API calls, and scale to any call volume.
  </Card>
  <Card title="Handle DNC requests immediately" icon="ban">
    Check `dnc_requested` in every `call.completed` webhook and add the prospect to your DNC list before doing anything else. This is a legal requirement in most jurisdictions.
  </Card>
  <Card title="Store run IDs" icon="bookmark">
    Persist `workflow_run_id` in your database alongside the CRM contact ID. This links your records to Nova sessions and calls for auditing and troubleshooting.
  </Card>
  <Card title="Schedule calls thoughtfully" icon="clock">
    Use `scheduled_at` to place calls during business hours for the prospect's timezone. Pass `timezone` in the prospect object to help Nova respect calling hour rules.
  </Card>
</CardGroup>
