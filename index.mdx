## What is Nova API?

Nova API is Cozmo AI's platform for building production-grade AI voice and chat agents. It gives you complete programmatic control over the full agent lifecycle:

## How it works

A typical integration follows this flow:

```
1. Create Agent       Configure LLM, voice, transcriber, and system prompt
        |
2. Create Workflow    Define multi-step interaction logic in the Dashboard
        |
3. Trigger Run        POST /workflow-runs with prospect phone + data
        |
4. Call Placed        Nova dials the prospect, agent conducts the conversation
        |
5. Webhook Fired      call.completed arrives with transcript, evaluations, recording
        |
6. Update Systems     CRM update, next-step scheduling, reporting
```

### Or start a session directly

For chat agents, inbound calls, or custom orchestration, skip workflows and start a session directly:

```
1. Create Agent       Configure LLM and channel settings
        |
2. Start Session      POST /agent-sessions/{uuid}/start with instruction
        |
3. Agent Runs         Nova processes the instruction and runs the agent
        |
4. Session Ends       session.completed webhook fires with results
```

## Base URL

```
https://v2-nova-api.prod.czmx.in/api
```

Every endpoint is scoped to your organization:

```
/org/{org_id}/agents
/org/{org_id}/agent-sessions/{session_id}/start
/org/{org_id}/calls
/org/{org_id}/workflows
/org/{org_id}/workflow-runs
/org/{org_id}/voices
```

Find your `org_id` in the [Dashboard](https://dash.prod.czmx.in) URL or in **Organization Settings**.

## Authentication

Every request requires your API key in the `X-API-Key` header:

```bash
curl https://v2-nova-api.prod.czmx.in/api/org/{org_id}/agents \
  -H "X-API-Key: YOUR_API_KEY"
```

Get your API key from [Dashboard - Organization Settings](https://dash.prod.czmx.in). See [Authentication](/authentication) for key management and security best practices.

## Resources at a glance

| Resource | Description | Key endpoints |
|----------|-------------|---------------|
| **Agents** | AI entities with LLM, voice, and transcriber configs | `GET/POST /agents`, `PATCH /agents/{id}` |
| **Agent Sessions** | Single run of an agent for a prospect | `POST /agent-sessions/{id}/start`, `GET /agent-sessions/{id}` |
| **Calls** | Voice call records with transcript, evaluations, recordings | `GET /calls`, `GET /calls/{id}` |
| **Voices** | Available TTS voices by provider | `GET /voices?provider=elevenlabs` |
| **Workflows** | Named multi-step interaction templates | `GET /workflows`, `GET /workflows/{id}` |
| **Workflow Runs** | Single execution of a workflow for a prospect | `POST /workflow-runs` |

## Webhook events

Configure a webhook URL in the Dashboard to receive real-time event notifications:

| Event | Fires when |
|-------|-----------|
| `call.completed` | Voice call finishes - includes transcript, evaluations, recording URL |
| `call.failed` | Voice call fails (no answer, busy, SIP error, validation failure) |
| `session.completed` | Agent session reaches COMPLETED or STOPPED |
| `session.failed` | Agent session reaches FAILED or CANCELLED |
