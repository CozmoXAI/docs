## Prerequisites

- [Windsurf](https://codeium.com/windsurf) installed
- Node.js **20.11** or later
- A Cozmo API key and Org ID from [Dashboard → Organization Settings](https://dash.prod.czmx.in)

## Step 1 - Clone and build the MCP server

```bash
git clone https://github.com/CozmoXAI/mcp-server.git ~/cozmox-mcp-server
cd ~/cozmox-mcp-server
npm install
npm run build
```

## Step 2 - Configure Windsurf

Create a `.windsurf/mcp.json` file at the root of your project:

```bash
mkdir -p .windsurf
```

```json .windsurf/mcp.json
{
  "mcpServers": {
    "cozmox": {
      "command": "node",
      "args": ["/absolute/path/to/cozmox-mcp-server/dist/stdio.js"],
      "env": {
        "COZMOX_API_BASE_URL": "https://v2-nova-api.prod.czmx.in",
        "COZMOX_ORG_ID": "YOUR_ORG_ID",
        "COZMOX_API_KEY": "YOUR_API_KEY",
        "COZMOX_ENABLE_WRITE_TOOLS": "false",
        "COZMOX_ENABLE_DESTRUCTIVE_TOOLS": "false"
      }
    }
  }
}
```

Replace `/absolute/path/to/cozmox-mcp-server` with the actual path where you cloned the repo.

<Warning>
  Keep API keys out of version control. Commit `.windsurf/mcp.json` without the `env` block and set `COZMOX_API_KEY` and `COZMOX_ORG_ID` in each developer's shell profile.
</Warning>

**Team-safe version** (no secrets in the file):

```json .windsurf/mcp.json
{
  "mcpServers": {
    "cozmox": {
      "command": "node",
      "args": ["/absolute/path/to/cozmox-mcp-server/dist/stdio.js"]
    }
  }
}
```

Each developer exports in their shell:

```bash
export COZMOX_API_KEY="your_api_key"
export COZMOX_ORG_ID="your_org_id"
```

## Step 3 - Reload Windsurf

Open the command palette and run **Windsurf: Reload Window**, or close and reopen Windsurf. Cascade will detect the MCP server automatically on next load.

## Step 4 - Verify

Open Cascade and ask:

> *"Use cozmox_health_check to verify my Cozmo connection"*

A correct response returns `{ "ok": true, "org_id": "..." }` — pulled live from the API.

## Available tools

### Read tools (always on)

| Tool | What it does |
|------|-------------|
| `cozmox_context` | Show server config — org ID and which tiers are enabled |
| `cozmox_health_check` | Verify API key and org connectivity |
| `cozmox_list_agents` | Paginated agent list; filter by `type` or `search` |
| `cozmox_get_agent` | Full details for one agent by UUID |
| `cozmox_list_calls` | Calls list with 12 filters (status, direction, agent, prospect, date range…) |
| `cozmox_get_call_details` | Full call record — transcript, evaluations, recording metadata, tool logs |
| `cozmox_list_voices` | Available voices by provider |
| `cozmox_list_workflows` | Paginated workflow list |
| `cozmox_get_workflow` | Single workflow with its latest definition |
| `cozmox_get_agent_session` | Agent session details by UUID |

### Write tools (`COZMOX_ENABLE_WRITE_TOOLS=true`)

| Tool | What it does |
|------|-------------|
| `cozmox_create_agent` | Create a new voice, chat, or video agent |
| `cozmox_update_agent` | Partial update of an existing agent |
| `cozmox_create_workflow_run_with_prospect` | Trigger a workflow run with a new or existing prospect |
| `cozmox_start_agent_session` | Start an agent session with an initial instruction |

### Destructive tools (`COZMOX_ENABLE_DESTRUCTIVE_TOOLS=true`)

| Tool | What it does |
|------|-------------|
| `cozmox_delete_agent` | Permanently delete an agent (requires literal confirmation) |

## Windsurf rules for Cozmo projects

Create a `.windsurf/rules.md` to give Cascade persistent context:

```markdown .windsurf/rules.md
# Cozmo / Nova API integration

## Project context
- Nova API base: https://v2-nova-api.prod.czmx.in/api
- Auth: X-API-Key header — value from COZMOX_API_KEY env var
- All endpoints scoped to /api/org/{org_id}/ — org ID from COZMOX_ORG_ID
- MCP server registered as "cozmox"

## Key patterns
- Session IDs must be client-generated UUID v4
- Phone numbers must be E.164 format (e.g. +19175551234)
- Retry 429 with exponential backoff; check X-Rate-Limit-Reset header
- Never retry 4xx — fix the request

## Resources
- Agents: GET/POST/PATCH/DELETE /agents
- Sessions: POST /agent-sessions/{session_id}/start
- Calls: GET /calls and /calls/{call_id}
- Workflow Runs: POST /workflow-runs
- Webhooks: call.completed, call.failed, session.completed, session.failed
```

## What you can ask Cascade

<AccordionGroup>
  <Accordion title="Listing agents and calls">
    > *"List my Cozmo voice agents and show the total call count for each"*

    Cascade calls `cozmox_list_agents` with `{ "type": "voice" }`, then can call `cozmox_list_calls` filtered by each agent ID.
  </Accordion>

  <Accordion title="Inspecting a call">
    > *"Get the full details for call [call_id] and show me the evaluations"*

    Cascade calls `cozmox_get_call_details` and returns the full record including `evaluations[]`, `transcript_text`, and `recording_url`.
  </Accordion>

  <Accordion title="Triggering workflow runs (write tools on)">
    > *"Create a workflow run for workflow [workflow_id] with prospect: phone +19175551234, name Jane Smith, email jane@example.com"*

    Cascade calls `cozmox_create_workflow_run_with_prospect`, which validates the workflow is visible before posting.
  </Accordion>

  <Accordion title="Starting sessions (write tools on)">
    > *"Start an agent session for agent [agent_id] with the instruction: follow up on the demo"*

    Cascade calls `cozmox_start_agent_session`, which pre-checks agent org ownership, then creates the session with an auto-generated UUID.
  </Accordion>
</AccordionGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Cascade doesn't use the MCP server">
    Confirm `.windsurf/mcp.json` is at the **root of the open workspace folder**. Reload Windsurf after any config changes.
  </Accordion>

  <Accordion title="node not found when Windsurf launches">
    Ensure Node.js 20.11+ is active and on PATH when Windsurf launches. If using nvm, activate the right version before opening Windsurf:

    ```bash
    nvm use 20
    ```
  </Accordion>

  <Accordion title="Environment variables not picked up">
    If `COZMOX_API_KEY` set in your shell profile isn't visible to Windsurf, add the `env` block explicitly to `.windsurf/mcp.json` for local dev and add the file to `.gitignore`.
  </Accordion>
</AccordionGroup>
