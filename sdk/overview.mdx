## Official SDKs

Cozmo AI publishes official server SDKs for the three most common backend languages. All SDKs are generated from the Nova API OpenAPI specification using [Stainless](https://stainless.com) and kept in sync with every API update.

## What the SDKs give you

Every SDK wraps the raw Nova REST API with:

- **Auto-generated types** for every request and response object
- **Authentication handling** - just pass your API key once at initialization
- **Automatic retries** with exponential backoff on 5xx errors
- **Pagination helpers** to iterate through large result sets
- **Error classes** that map HTTP status codes to typed exceptions

## Resources available in every SDK

| Resource | Methods |
|----------|---------|
| `agents` | `list`, `create`, `retrieve`, `update`, `delete` |
| `agentSessions` | `start`, `retrieve` |
| `calls` | `list`, `retrieve` |
| `voices` | `list` |
| `workflows` | `list`, `retrieve` |

<Note>
  `workflow_runs` is not yet available as an SDK resource. Use the REST API directly: `POST /org/{org_id}/workflow-runs`. See the [Python SDK](/sdk/python#workflow-runs) page for a helper function.
</Note>

## Authentication

All SDKs read credentials from the environment by default. Pass `base_url` explicitly to scope requests to your org:

<CodeGroup>

```python Python
import os
from cozmoxai import Cozmoai

client = Cozmoai(
    api_key=os.environ["COZMOAI_API_KEY"],
    base_url=f"https://v2-nova-api.prod.czmx.in/api/org/{os.environ['COZMOAI_ORG_ID']}",
)
```

```typescript TypeScript
import CozmoAI from "cozmoai";

// Reads COZMO_API_KEY from environment
const client = new CozmoAI();

// Or pass explicitly
const client = new CozmoAI({ apiKey: "YOUR_API_KEY" });
```

</CodeGroup>

## Environment setup

<CodeGroup>

```bash Python
export COZMOAI_API_KEY="your_api_key_here"
export COZMOAI_ORG_ID="your_org_id_here"
```

```bash TypeScript
export COZMO_API_KEY="your_api_key_here"
export COZMO_ORG_ID="your_org_id_here"
```

</CodeGroup>

Or use a `.env` file (load with `python-dotenv`, `dotenv`, or `godotenv`):

<CodeGroup>

```bash Python .env
COZMOAI_API_KEY=your_api_key_here
COZMOAI_ORG_ID=your_org_id_here
```

```bash TypeScript .env
COZMO_API_KEY=your_api_key_here
COZMO_ORG_ID=your_org_id_here
```

</CodeGroup>

If your stack uses a language not listed above, use the [REST API](/api-reference/introduction) directly. Every endpoint is documented with `curl` examples and full request/response schemas.
