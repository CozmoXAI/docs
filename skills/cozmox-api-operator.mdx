## Overview

The `cozmox-api-operator` skill gives your AI coding assistant precise, safety-first knowledge for creating and managing Cozmo agents via the Nova API. Use it to generate correct `POST /agents` payloads with every field, perform org-scoped CRUD operations, write TypeScript or Python clients, and hand off the resulting `agent_id` to the Workflow Builder skill.

## Install

```bash
npx skills add CozmoXAI/skills --skill cozmox-api-operator -a claude-code -y
```

## Compose with the Workflow Builder

```
cozmox-api-operator  →  agent_id
                                ↓  (attach agent to workflow in Dashboard)
          cozmox-workflow-builder  →  workflow_id
                                ↓
            cozmox-workflow-runner  →  workflow_run_id
```

`agent_id` is not passed directly to workflow runs — the workflow already has an agent configured. Use this skill to create the agent, then attach it to a workflow in the Dashboard before triggering runs.

## Create agent — endpoint

```http
POST /api/org/{org_id}/agents
```

## Safety contract

Before generating or executing any agent command:

1. Use `COZMOX_ORG_ID` from environment — never ask the user to supply an org ID.
2. Never print a live `COZMOX_API_KEY`.
3. Never put `X-API-Key` in browser or client-side code. API calls must run server-side.
4. For cloning, validate the source agent exists under the configured org before generating the payload.
5. Treat `POST`, `PATCH`, and `DELETE` as side-effecting — state the side effect before executing.
6. Before any write that references an agent ID, validate that agent via `GET /agents/{agent_id}` first.
7. After creation, return `agent_id` and the next verification command only.

## Environment contract

```bash
COZMOX_API_BASE_URL="https://v2-nova-api.prod.czmx.in"
COZMOX_ORG_ID="your-org-uuid"
COZMOX_API_KEY="czmx_..."
```

All URLs follow this pattern:

```
${COZMOX_API_BASE_URL}/api/org/${COZMOX_ORG_ID}/${resource_path}
```

## Preflight — validate org before writing

```bash
curl --request GET \
  --url "$COZMOX_API_BASE_URL/api/org/$COZMOX_ORG_ID/agents?page=1&size=1" \
  --header "X-API-Key: $COZMOX_API_KEY"
```

If this returns `401` or `403`, do not proceed. Report the auth failure to the user.

## Clone an existing agent

```bash
curl --request POST \
  --url "$COZMOX_API_BASE_URL/api/org/$COZMOX_ORG_ID/agents" \
  --header "Content-Type: application/json" \
  --header "X-API-Key: $COZMOX_API_KEY" \
  --data '{
    "name": "Sales Agent — B Variant",
    "copy_from_agent_id": "'"$SOURCE_AGENT_ID"'",
    "prompt_template": "Alternate opener that leads with value proposition first..."
  }'
```

All fields from the source agent are copied. Only the fields you specify override the clone.

## Update an agent (PATCH)

`PATCH` only changes the fields you send. All other settings remain unchanged.

```bash
curl --request PATCH \
  --url "$COZMOX_API_BASE_URL/api/org/$COZMOX_ORG_ID/agents/$AGENT_ID" \
  --header "Content-Type: application/json" \
  --header "X-API-Key: $COZMOX_API_KEY" \
  --data '{
    "prompt_template": "Updated prompt...",
    "llm_config": { "provider": "openai", "model": "gpt-4o", "temperature": 0.5 }
  }'
```

## TypeScript client

```typescript
export type CozmoxConfig = {
  baseUrl: string;
  orgId: string;
  apiKey: string;
};

export async function agentRequest<T>(
  config: CozmoxConfig,
  method: "GET" | "POST" | "PATCH" | "DELETE",
  path: string,
  body?: unknown,
): Promise<T> {
  if (!path.startsWith("/")) path = `/${path}`;
  if (path.includes("/api/org/")) throw new Error("path must be relative to /api/org/{org_id}");

  const response = await fetch(`${config.baseUrl}/api/org/${config.orgId}${path}`, {
    method,
    headers: {
      "X-API-Key": config.apiKey,
      ...(body === undefined ? {} : { "Content-Type": "application/json" }),
    },
    body: body === undefined ? undefined : JSON.stringify(body),
  });

  const text = await response.text();
  const data = text ? JSON.parse(text) : null;
  if (!response.ok) {
    throw new Error(`Cozmo API ${method} ${path} failed: ${response.status} ${JSON.stringify(data)}`);
  }
  return data as T;
}
```

## Browse available voices

Before setting `voice_config.voice_id`, list available voices for a provider:

```bash
curl --request GET \
  --url "$COZMOX_API_BASE_URL/api/org/$COZMOX_ORG_ID/voices?provider=elevenlabs" \
  --header "X-API-Key: $COZMOX_API_KEY"
```
