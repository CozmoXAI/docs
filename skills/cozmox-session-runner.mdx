## Overview

The `cozmox-session-runner` skill makes your AI coding assistant an expert at creating and configuring Cozmo agents. Use it to generate correct `POST /agents` payloads with every field — LLM, transcriber, voice, greeting, VAD, interruption settings — validate the agent under your org, and hand off the resulting agent ID to the Workflow Runner skill.

## Install

```bash
npx skills add CozmoXAI/skills --skill cozmox-session-runner -a claude-code -y
```

## Compose with the Workflow Runner

This skill produces an `agent_id`. Pass it to [`cozmox-workflow-runner`](/skills/cozmox-workflow-runner) to trigger calls:

```
cozmox-session-runner  →  agent_id
                                 ↓
               cozmox-workflow-runner  →  workflow_run_id
```

## Create agent — endpoint

```http
POST /api/org/{org_id}/agents
```

## Safety contract

Before generating or executing any agent creation command:

1. Use `COZMOX_ORG_ID` from environment — never ask the user to supply an org ID.
2. Never print a live `COZMOX_API_KEY`.
3. For cloning, validate the source agent exists under the configured org before generating the payload.
4. After creation, return the `agent_id` and the next verification command.
5. State the side effect before making any write call.

## Preflight — validate org before writing

```bash
# Confirm the org is reachable and your key is valid
curl --request GET \
  --url "$COZMOX_API_BASE_URL/api/org/$COZMOX_ORG_ID/agents?page=1&size=1" \
  --header "X-API-Key: $COZMOX_API_KEY"
```

If this returns `401` or `403`, do not proceed. Report the auth failure to the user.

## Minimal create payload (voice agent)

```bash
curl --request POST \
  --url "$COZMOX_API_BASE_URL/api/org/$COZMOX_ORG_ID/agents" \
  --header "Content-Type: application/json" \
  --header "X-API-Key: $COZMOX_API_KEY" \
  --data '{
    "name": "Sales Agent — US Market",
    "type": "voice",
    "prompt_template": "You are Alex, a friendly sales representative for Acme Corp. Your goal is to qualify {{prospect_name}} and schedule a demo. Be concise — this is a phone call. Ask one question at a time.",
    "llm_config": {
      "provider": "openai",
      "model": "gpt-4o",
      "temperature": 0.7,
      "max_tokens": 200,
      "fallbacks": [
        { "provider": "anthropic", "model": "claude-3-5-sonnet-20241022" }
      ]
    },
    "transcriber_config": {
      "provider": "deepgram",
      "model": "nova-3",
      "language": "en-US",
      "endpointing_ms": 300,
      "smart_format": true
    },
    "voice_config": {
      "provider": "elevenlabs",
      "voice_id": "21m00Tcm4TlvDq8ikWAM",
      "model": "eleven_turbo_v2_5"
    },
    "greeting_config": {
      "agent_speaks_first": true,
      "greeting": "Hi, is this {{prospect_name}}? This is Alex from Acme Corp — do you have two minutes?",
      "pause_before_first_message": 800,
      "voice_mail_message": "Hi {{prospect_name}}, this is Alex from Acme. I will try you again soon."
    }
  }'
```

## Clone an existing agent

```bash
curl --request POST \
  --url "$COZMOX_API_BASE_URL/api/org/$COZMOX_ORG_ID/agents" \
  --header "Content-Type: application/json" \
  --header "X-API-Key: $COZMOX_API_KEY" \
  --data '{
    "name": "Sales Agent — B Variant",
    "copy_from_agent_id": "'"$SOURCE_AGENT_ID"'",
    "prompt_template": "Alternate opener that leads with value proposition first..."
  }'
```

All fields from the source agent are copied. Only the fields you specify override the clone.

## Update an agent (PATCH)

`PATCH` only changes the fields you send. All other settings remain unchanged.

```bash
curl --request PATCH \
  --url "$COZMOX_API_BASE_URL/api/org/$COZMOX_ORG_ID/agents/$AGENT_ID" \
  --header "Content-Type: application/json" \
  --header "X-API-Key: $COZMOX_API_KEY" \
  --data '{
    "prompt_template": "Updated prompt...",
    "llm_config": {
      "provider": "openai",
      "model": "gpt-4o",
      "temperature": 0.5,
      "max_tokens": 180
    }
  }'
```

## Post-create verification

```bash
curl --request GET \
  --url "$COZMOX_API_BASE_URL/api/org/$COZMOX_ORG_ID/agents/$AGENT_ID" \
  --header "X-API-Key: $COZMOX_API_KEY"
```

## Browsing available voices

Before setting `voice_config.voice_id`, list available voices:

```bash
curl --request GET \
  --url "$COZMOX_API_BASE_URL/api/org/$COZMOX_ORG_ID/voices?provider=elevenlabs" \
  --header "X-API-Key: $COZMOX_API_KEY"
```
