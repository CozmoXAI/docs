## What are Agent Skills?

Agent Skills are portable instruction files (each a `SKILL.md`) that you install into your AI coding assistant — Claude Code, Cursor, Windsurf, Codex, GitHub Copilot, or any agent that supports the open Agent Skills layout. Once installed, your agent knows exactly how to operate, code, and reason about Cozmo APIs and infrastructure without hallucinating endpoints, leaking credentials, or skipping safety checks.

Each skill is a folder containing a `SKILL.md` plus optional helper scripts. They are installed via the `npx skills` CLI from a GitHub repository or local path.

## Installation

### From GitHub

```bash
# List available skills
npx skills add CozmoXAI/skills --list

# Install all skills for your agent
npx skills add CozmoXAI/skills --skill '*' -a claude-code -y
npx skills add CozmoXAI/skills --skill '*' -a cursor -y
npx skills add CozmoXAI/skills --skill '*' -a codex -y

# Install a single skill globally
npx skills add CozmoXAI/skills --skill cozmox-api-operator -g -a claude-code -y
```

### From a local clone

```bash
git clone https://github.com/CozmoXAI/skills.git
npx skills add ./skills --list
npx skills add ./skills --skill '*' -a claude-code -y
```

Supported agent IDs include: `claude-code`, `cursor`, `windsurf`, `opencode`, `github-copilot`, `codex`.

## Environment setup

For skills that make live API calls, set these in trusted local or server environments only — never commit them:

```bash
export COZMOX_API_BASE_URL="https://v2-nova-api.prod.czmx.in"
export COZMOX_ORG_ID="your-org-uuid"
export COZMOX_API_KEY="czmx_..."
```

Optional write gate for the bundled API wrapper:

```bash
export COZMOX_ALLOW_WRITES="true"
```

## Security defaults shared by all skills

Every skill in this bundle enforces the same safety contract:

- `COZMOX_ORG_ID` is never a user-supplied argument. Agents read it from trusted environment or server config.
- API keys stay server-side. No skill will ask the user to paste a live key into code, logs, or chat.
- Read-only operations are preferred. Writes require explicit user intent and a confirmation step.
- Before writing agents or triggering workflow runs, the resource is always validated under the configured org.
- Destructive operations require a second confirmation and should normally route through the MCP server's destructive-tool gate.

## Validate the bundle

After cloning, run the built-in validator to confirm all skills have valid frontmatter:

```bash
cd skills
node scripts/validate-skills.mjs
```
