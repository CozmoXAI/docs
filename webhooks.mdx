## Overview

Webhooks let you receive real-time notifications when events occur in your Cozmo AI account. Instead of polling the API, Cozmo pushes a signed HTTP `POST` request to your endpoint the moment an event fires.

Nova sends four event types:

<CardGroup cols={2}>
  <Card title="call.completed" icon="phone-check">
    A voice call finished - includes transcript, recording URL, evaluations, and prospect data.
  </Card>
  <Card title="call.failed" icon="phone-xmark">
    A call failed due to a technical error, SIP issue, no answer, busy line, or validation failure.
  </Card>
  <Card title="session.completed" icon="circle-check">
    An agent session reached `COMPLETED` or `STOPPED` status.
  </Card>
  <Card title="session.failed" icon="circle-xmark">
    An agent session reached `FAILED` or `CANCELLED` status.
  </Card>
</CardGroup>

## Webhook setup

<Steps>
  <Step title="Open Dashboard settings">
    Go to [Dashboard](https://dash.prod.czmx.in) and navigate to **Organization Settings** then **Webhooks**.
  </Step>
  <Step title="Add your endpoint URL">
    Enter the full HTTPS URL where Nova should deliver events, for example `https://api.yourapp.com/webhooks/cozmo`. Nova requires HTTPS in production.
  </Step>
  <Step title="Copy your signing secret">
    After saving, copy the generated **Signing Secret**. You will use it to verify the `X-Cozmo-Signature` header on incoming requests.
  </Step>
  <Step title="Select events">
    Choose which events to receive. You can subscribe to all four or only the ones relevant to your integration.
  </Step>
</Steps>

<Info>
  Nova delivers each event as an HTTP `POST` with `Content-Type: application/json`. Your endpoint must respond with a `2xx` status within **10 seconds**.
</Info>

## Manage webhooks via API

If you want to provision webhook endpoints programmatically instead of using the Dashboard, use the global webhook endpoints in the API reference.

Typical workflow:

- `GET /org/{org_id}/global-webhooks` to list configured endpoints
- `POST /org/{org_id}/global-webhooks` to create a new endpoint
- `PATCH /org/{org_id}/global-webhooks/{webhook_id}` to rotate URLs or subscribed events
- `DELETE /org/{org_id}/global-webhooks/{webhook_id}` to remove an endpoint

Example create request:

```bash
curl -X POST "https://v2-nova-api.prod.czmx.in/api/org/{org_id}/global-webhooks" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://api.yourapp.com/webhooks/cozmo",
    "events": ["call.completed", "call.failed", "session.completed", "session.failed"],
    "is_active": true
  }'
```

<Tip>
  The payload schema for webhook management lives in the API Reference under the `Webhooks` tag. Use that reference as the source of truth for available fields and event names.
</Tip>

## Signature verification

Every webhook request includes an `X-Cozmo-Signature` header. This is an HMAC-SHA256 hex digest of the raw request body, signed with your webhook signing secret.

**Always verify signatures before processing a payload.** This confirms the request came from Cozmo and the body has not been tampered with.

<Warning>
  Compute the signature over the **raw bytes** of the request body before any JSON parsing. Parsing the JSON and re-serializing it can change whitespace or key ordering, causing the signature check to fail.
</Warning>

<CodeGroup>

```javascript Node.js
import crypto from "crypto";

function verifyCozmoSignature(
  rawBody: Buffer | string,
  signatureHeader: string,
  signingSecret: string
): boolean {
  const expected = crypto
    .createHmac("sha256", signingSecret)
    .update(rawBody)
    .digest("hex");

  // Use timingSafeEqual to prevent timing attacks
  const expectedBuf = Buffer.from(expected, "hex");
  const receivedBuf = Buffer.from(signatureHeader, "hex");

  if (expectedBuf.length !== receivedBuf.length) return false;
  return crypto.timingSafeEqual(expectedBuf, receivedBuf);
}

// Express example - use express.raw() to capture raw body
import express from "express";
const app = express();

app.post(
  "/webhooks/cozmo",
  express.raw({ type: "application/json" }),
  (req, res) => {
    const signature = req.headers["x-cozmo-signature"] as string;

    if (!verifyCozmoSignature(req.body, signature, process.env.COZMO_WEBHOOK_SECRET!)) {
      return res.status(401).json({ error: "Invalid signature" });
    }

    const payload = JSON.parse(req.body.toString());
    // process payload...
    res.json({ ok: true });
  }
);
```

```python Python
import hashlib
import hmac
import os
from fastapi import FastAPI, Request, HTTPException

app = FastAPI()

def verify_cozmo_signature(raw_body: bytes, signature: str, secret: str) -> bool:
    expected = hmac.new(
        secret.encode("utf-8"),
        raw_body,
        hashlib.sha256,
    ).hexdigest()
    return hmac.compare_digest(expected, signature)

@app.post("/webhooks/cozmo")
async def cozmo_webhook(request: Request):
    raw_body = await request.body()
    signature = request.headers.get("x-cozmo-signature", "")
    secret = os.environ["COZMO_WEBHOOK_SECRET"]

    if not verify_cozmo_signature(raw_body, signature, secret):
        raise HTTPException(status_code=401, detail="Invalid signature")

    payload = await request.json()
    # process payload...
    return {"ok": True}
```

```go Go
package main

import (
    "crypto/hmac"
    "crypto/sha256"
    "encoding/hex"
    "encoding/json"
    "io"
    "net/http"
    "os"
)

func verifyCozmoSignature(rawBody []byte, signature, secret string) bool {
    mac := hmac.New(sha256.New, []byte(secret))
    mac.Write(rawBody)
    expected := hex.EncodeToString(mac.Sum(nil))
    return hmac.Equal([]byte(expected), []byte(signature))
}

func webhookHandler(w http.ResponseWriter, r *http.Request) {
    rawBody, err := io.ReadAll(r.Body)
    if err != nil {
        http.Error(w, "failed to read body", http.StatusBadRequest)
        return
    }

    signature := r.Header.Get("X-Cozmo-Signature")
    secret := os.Getenv("COZMO_WEBHOOK_SECRET")

    if !verifyCozmoSignature(rawBody, signature, secret) {
        http.Error(w, "invalid signature", http.StatusUnauthorized)
        return
    }

    var payload map[string]json.RawMessage
    if err := json.Unmarshal(rawBody, &payload); err != nil {
        http.Error(w, "invalid json", http.StatusBadRequest)
        return
    }

    // process payload...
    w.Header().Set("Content-Type", "application/json")
    w.Write([]byte(`{"ok":true}`))
}
```

## Call result types

| Result | Description |
|--------|-------------|
| `FINISHED` | Call connected and completed normally |
| `FAILED` | Technical failure during the call |
| `FAILED_VALIDATION` | Pre-call validation check failed (e.g. invalid number format) |
| `FAILED_SIP` | SIP/trunk-level connection error |
| `ANALYSIS_FAILED` | Call connected but post-call analysis could not complete |
| `NO_ANSWER` | Prospect did not pick up |
| `BUSY` | Prospect's line was busy |
| `CANCELLED` | Call was cancelled before connecting |

## Retry and delivery behavior

When your endpoint does not respond with a `2xx` status within 10 seconds, Nova retries the event with exponential backoff:

| Attempt | Delay |
|---------|-------|
| 1 (initial) | Immediate |
| 2 | 30 seconds |
| 3 | 5 minutes |
| 4 (final) | 30 minutes |

After 4 failed attempts, the event is marked as failed and will not be retried. You can view delivery failures in [Dashboard - Webhook Logs](https://dash.prod.czmx.in).

<Info>
  `4xx` responses (except `429 Too Many Requests`) are treated as permanent rejections and are **not** retried. Return a `5xx` if you want Nova to retry.
</Info>

## Deduplication

Events can arrive more than once due to retries. Always implement idempotent processing using the event's primary identifier as a key:

- **Call events**: deduplicate on `data.call_id`
- **Session events**: deduplicate on `data.session_id`

Additionally, events are not guaranteed to arrive in order. Use `last_event_sequence` on session events to detect out-of-order delivery.

```javascript Node.js
const processedEvents = new Set(); // use Redis or a database in production

app.post("/webhooks/cozmo", express.raw({ type: "application/json" }), (req, res) => {
  const payload = JSON.parse(req.body.toString());
  const { event, data } = payload;

  // Idempotency key depends on event type
  const key = data.call_id ?? data.session_id;
  const dedupKey = `${event}:${key}`;

  if (processedEvents.has(dedupKey)) {
    return res.json({ ok: true, skipped: true });
  }
  processedEvents.add(dedupKey);

  // Process the event...
  res.json({ ok: true });
});
```

## Async processing pattern

Never do slow work (database writes, external API calls, sending emails) synchronously in your webhook handler. Acknowledge the event immediately and process in the background.

<CodeGroup>

```javascript Node.js / Express
import express from "express";
import crypto from "crypto";

const app = express();

app.post(
  "/webhooks/cozmo",
  express.raw({ type: "application/json" }),
  (req, res) => {
    const signature = req.headers["x-cozmo-signature"] as string;
    if (!verifyCozmoSignature(req.body, signature, process.env.COZMO_WEBHOOK_SECRET!)) {
      return res.status(401).json({ error: "Invalid signature" });
    }

    // Acknowledge immediately - Cozmo expects a response within 10 seconds
    res.json({ ok: true });

    // Process asynchronously after responding
    const payload = JSON.parse(req.body.toString());
    processWebhookAsync(payload).catch((err) => {
      console.error("Webhook processing error:", err);
    });
  }
);

async function processWebhookAsync(payload: { event: string; data: any }) {
  const { event, data } = payload;

  switch (event) {
    case "call.completed": {
      const { call_id, call_result, prospect, evaluations, summary, transcript } = data;

      // Index evaluations by key for easy lookup
      const evals = Object.fromEntries(
        (evaluations ?? []).map((e: any) => [e.key, e])
      );

      console.log(`Call ${call_id} finished: ${call_result}`);

      if (call_result === "FINISHED") {
        // Update CRM with outcome
        if (evals.INTERESTED?.result_boolean) {
          await updateCRM(prospect.ExternalId, {
            status: "interested",
            notes: summary,
          });
        }
        // Store transcript
        await saveTranscript(call_id, transcript);
      } else {
        // Handle non-answer, busy, etc.
        await scheduleRetry(prospect.ExternalId, call_result);
      }
      break;
    }

    case "call.failed": {
      const { call_id, call_result, prospect } = data;
      console.warn(`Call ${call_id} failed: ${call_result}`);
      await logCallFailure(call_id, call_result, prospect?.ExternalId);
      break;
    }

    case "session.completed": {
      const { session_id, duration_seconds, channel, metadata } = data;
      console.log(`Session ${session_id} completed in ${duration_seconds}s on ${channel}`);
      await updateSessionMetrics(session_id, duration_seconds, metadata);
      break;
    }

    case "session.failed": {
      const { session_id, status } = data;
      console.warn(`Session ${session_id} failed with status: ${status}`);
      await alertOpsTeam(session_id, status);
      break;
    }
  }
}

app.listen(3000, () => console.log("Webhook server running on :3000"));
```

```python Python / FastAPI
    expected = hmac.new(secret.encode(), raw_body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, signature)

async def process_event(event: str, data: dict):
    """Background task - runs after 200 is returned."""
    if event == "call.completed":
        call_id = data["call_id"]
        call_result = data["call_result"]
        prospect = data.get("prospect", {})
        evaluations = {e["key"]: e for e in data.get("evaluations", [])}

        print(f"Call {call_id} finished: {call_result}")

        if call_result == "FINISHED":
            if evaluations.get("INTERESTED", {}).get("result_boolean"):

                    external_id=prospect.get("ExternalId"),
                    status="interested",
                    notes=data.get("summary"),
                )
            await save_transcript(call_id, data.get("transcript"))
        else:
            await schedule_retry(prospect.get("ExternalId"), call_result)

    elif event == "call.failed":
        print(f"Call {data['call_id']} failed: {data['call_result']}")
        await log_failure(data["call_id"], data["call_result"])

    elif event == "session.completed":
        print(f"Session {data['session_id']} completed in {data['duration_seconds']}s")
        await update_metrics(data["session_id"], data["duration_seconds"])

    elif event == "session.failed":
        print(f"Session {data['session_id']} failed: {data['status']}")
        await alert_ops(data["session_id"], data["status"])

@app.post("/webhooks/cozmo")
async def cozmo_webhook(request: Request, background_tasks: BackgroundTasks):
    raw_body = await request.body()
    signature = request.headers.get("x-cozmo-signature", "")

    if not verify_signature(raw_body, signature):
        raise HTTPException(status_code=401, detail="Invalid signature")

    payload = await request.json()
    event = payload.get("event")
    data = payload.get("data", {})

    # Queue background processing - response is sent before this runs
    background_tasks.add_task(process_event, event, data)

    # Acknowledge immediately
    return {"ok": True}
```

```go Go / net/http
func verifySignature(rawBody []byte, signature, secret string) bool {
    mac := hmac.New(sha256.New, []byte(secret))
    mac.Write(rawBody)
    expected := hex.EncodeToString(mac.Sum(nil))
    return hmac.Equal([]byte(expected), []byte(signature))
}

func processEvent(ctx context.Context, event string, rawData json.RawMessage) {
    switch event {
    case "call.completed":
        var d CallData
        if err := json.Unmarshal(rawData, &d); err != nil {
            log.Printf("error parsing call data: %v", err)
            return
        }
        log.Printf("Call %s finished: %s", d.CallID, d.CallResult)

        // Build evaluation map
        evals := make(map[string]Evaluation)
        for _, e := range d.Evaluations {
            evals[e.Key] = e
        }

        if interested, ok := evals["INTERESTED"]; ok && interested.ResultBoolean {
            // updateCRM(d.Prospect.ExternalId, "interested")
            log.Printf("Prospect %s is interested", d.Prospect.ExternalId)
        }

    case "call.failed":
        var d CallData
        json.Unmarshal(rawData, &d)
        log.Printf("Call %s failed: %s", d.CallID, d.CallResult)

    case "session.completed":
        var d SessionData
        json.Unmarshal(rawData, &d)
        log.Printf("Session %s completed in %ds on %s", d.SessionID, d.DurationSeconds, d.Channel)

    case "session.failed":
        var d SessionData
        json.Unmarshal(rawData, &d)
        log.Printf("Session %s failed: %s", d.SessionID, d.Status)
    }
}

func webhookHandler(w http.ResponseWriter, r *http.Request) {
    rawBody, err := io.ReadAll(r.Body)
    if err != nil {
        http.Error(w, "failed to read body", http.StatusBadRequest)
        return
    }

    signature := r.Header.Get("X-Cozmo-Signature")
    secret := os.Getenv("COZMO_WEBHOOK_SECRET")

    if !verifySignature(rawBody, signature, secret) {
        http.Error(w, "invalid signature", http.StatusUnauthorized)
        return
    }

    var payload WebhookPayload
    if err := json.Unmarshal(rawBody, &payload); err != nil {
        http.Error(w, "invalid json", http.StatusBadRequest)
        return
    }

    // Respond immediately, then process in background goroutine
    w.Header().Set("Content-Type", "application/json")
    w.Write([]byte(`{"ok":true}`))

    go processEvent(r.Context(), payload.Event, payload.Data)
}

func main() {
    http.HandleFunc("/webhooks/cozmo", webhookHandler)
    fmt.Println("Webhook server listening on :3000")
    log.Fatal(http.ListenAndServe(":3000", nil))
}
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Signature verification failing">
    The most common cause is parsing the JSON body before computing the HMAC. You must compute the signature over the **raw bytes** of the request body. In Express, use `express.raw({ type: 'application/json' })` instead of `express.json()`. In FastAPI, use `await request.body()` before `await request.json()`.
  </Accordion>

  <Accordion title="Events not arriving">
    Check that:
    - Your webhook URL is HTTPS and publicly reachable
    - Your server returns `2xx` within 10 seconds
    - The correct events are enabled in Dashboard - Webhook Settings
    - Your endpoint is not returning `4xx` (which stops retries)

    View delivery history in [Dashboard - Webhook Logs](https://dash.prod.czmx.in) to see exact response codes and error messages.
  </Accordion>

  <Accordion title="Duplicate events being processed">
    Cozmo retries on non-2xx responses, so your handler may receive the same event multiple times. Store processed `call_id` or `session_id` values in Redis or your database and skip events you have already handled.
  </Accordion>

  <Accordion title="Timeout errors in Dashboard logs">
    Your handler is taking more than 10 seconds. Move all slow operations (DB writes, external API calls, sending emails) to a background queue or goroutine. Respond `200` first, then process.
  </Accordion>

  <Accordion title="Events arriving out of order">
    This can happen when retries cause a later event delivery to overtake an earlier one. For session events, use `last_event_sequence` to detect ordering. For call events, use the `call_result` field as the authoritative outcome rather than relying on delivery order.
  </Accordion>
</AccordionGroup>

## Best practices

### Security

- Always verify the `X-Cozmo-Signature` header before processing any payload.
- Use `crypto.timingSafeEqual` (Node.js), `hmac.compare_digest` (Python), or `hmac.Equal` (Go) to prevent timing attacks.
- Store your signing secret in an environment variable or secrets manager, never in source code.
- Only accept requests over HTTPS.

### Reliability

- Respond `200` immediately and process in the background. This is the single most important reliability pattern.
- Implement idempotent handlers using `call_id` or `session_id` as the deduplication key.
- Store event IDs in a database (not in-process memory) so restarts do not cause reprocessing.
- Return `5xx` (not `4xx`) when you want Cozmo to retry. Return `2xx` once you have durably queued the work.

### CRM integration patterns

Use `prospect.ExternalId` (set when creating the prospect or running a workflow) to look up the record in your CRM:

```javascript
case "call.completed": {
  const { prospect, evaluations, summary } = data;

  // Map evaluations to outcome flags
  const evals = Object.fromEntries(
    evaluations.map((e) => [e.key, e.result_boolean])
  );

  await crm.updateContact(prospect.ExternalId, {
    lastCallResult: data.call_result,
    interested: evals.INTERESTED ?? false,
    dnc: data.dnc_requested,
    callNotes: summary,
    lastContactedAt: new Date().toISOString(),
  });
  break;
}
```

Set `external_id` consistently when creating prospects via the workflow-runs API so the `ExternalId` field in webhook payloads always maps directly to your CRM records.
