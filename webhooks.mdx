## Overview

Webhooks allow you to receive real-time notifications when events occur in your Cozmo AI account. Configure your webhook endpoint in your dashboard to start receiving events.

## Events

| Event               | Description                                                   |
| ------------------- | ------------------------------------------------------------- |
| `call.completed`    | Fired when a call finishes successfully or is analyzed        |
| `call.failed`       | Fired when a call fails due to technical or validation issues |
| `session.completed` | Fired when a session reaches `COMPLETED` or `STOPPED` status  |
| `session.failed`    | Fired when a session reaches `FAILED` or `CANCELLED` status   |

## Call Result Types

| Result              | Description                 |
| ------------------- | --------------------------- |
| `FINISHED`          | Successfully completed call |
| `FAILED`            | Technical failure           |
| `FAILED_VALIDATION` | Validation error            |
| `FAILED_SIP`        | SIP/trunk error             |
| `ANALYSIS_FAILED`   | Post-call analysis failed   |
| `NO_ANSWER`         | No pickup                   |
| `BUSY`              | Line was busy               |
| `CANCELLED`         | Cancelled                   |

## Payload Structure

<ResponseField name="event" type="string" required>
  The event type. One of `call.completed` or `call.failed`.
</ResponseField>

<ResponseField name="data" type="object" required>
  <Expandable title="data properties">
    <ResponseField name="call_id" type="string">
      Unique identifier for the call.
    </ResponseField>
    <ResponseField name="call_result" type="string">
      The result of the call. See [Call Result Types](#call-result-types) above.
    </ResponseField>
    <ResponseField name="campaign_count" type="integer">
      Number of campaign attempts.
    </ResponseField>
    <ResponseField name="dnc_requested" type="boolean">
      Whether the prospect requested to be added to the Do Not Call list.
    </ResponseField>
    <ResponseField name="evaluations" type="array">
      Post-call evaluation results.
      <Expandable title="evaluation object">
        <ResponseField name="key" type="string">
          Evaluation key (e.g., `SENTIMENT`, `SUMMARY`, `CALLBACK_REQUESTED`).
        </ResponseField>
        <ResponseField name="extracted_value" type="string">
          The extracted value from the evaluation.
        </ResponseField>
        <ResponseField name="reasoning" type="string">
          Reasoning behind the evaluation result.
        </ResponseField>
        <ResponseField name="result_boolean" type="boolean">
          Boolean result of the evaluation.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="extras" type="object | null">
      Additional metadata.
    </ResponseField>
    <ResponseField name="prospect" type="object">
      Prospect information.
      <Expandable title="prospect properties">
        <ResponseField name="ID" type="string">
          Unique identifier for the prospect.
        </ResponseField>
        <ResponseField name="ExternalId" type="string">
          External identifier for integration purposes.
        </ResponseField>
        <ResponseField name="FullName" type="string">
          Full name of the prospect.
        </ResponseField>
        <ResponseField name="Email" type="string">
          Email address of the prospect.
        </ResponseField>
        <ResponseField name="Phone" type="string">
          Phone number of the prospect.
        </ResponseField>
        <ResponseField name="Status" type="string">
          Current status of the prospect.
        </ResponseField>
        <ResponseField name="ExtraMetadata" type="object">
          Custom metadata fields.
        </ResponseField>
        <ResponseField name="CreatedAt" type="string">
          ISO 8601 timestamp of prospect creation.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="recording_url" type="string">
      URL to the call recording (if available).
    </ResponseField>
    <ResponseField name="sentiment" type="string">
      Overall sentiment of the call (e.g., `positive`, `neutral`, `negative`).
    </ResponseField>
    <ResponseField name="summary" type="string">
      AI-generated summary of the call.
    </ResponseField>
    <ResponseField name="transcript" type="string">
      Full transcript of the call.
    </ResponseField>
  </Expandable>
</ResponseField>

## Session Events

Session webhooks fire when an agent session reaches a terminal state.

### Session Payload Structure

<ResponseField name="event" type="string" required>
  The event type. One of `session.completed` or `session.failed`.
</ResponseField>

<ResponseField name="data" type="object" required>
  <Expandable title="data properties">
    <ResponseField name="session_id" type="string">
      Unique identifier for the session.
    </ResponseField>
    <ResponseField name="organization_id" type="string">
      Unique identifier for the organization.
    </ResponseField>
    <ResponseField name="status" type="string">
      Terminal status of the session. One of `COMPLETED`, `STOPPED`, `FAILED`, or `CANCELLED`.
    </ResponseField>
    <ResponseField name="root_agent_id" type="string | null">
      Identifier of the root agent that ran the session.
    </ResponseField>
    <ResponseField name="prospect_id" type="string | null">
      Identifier of the prospect associated with the session.
    </ResponseField>
    <ResponseField name="call_id" type="string | null">
      Identifier of the call associated with the session, if any.
    </ResponseField>
    <ResponseField name="channel" type="string | null">
      Communication channel (e.g. `telegram`, `whatsapp`, `slack`).
    </ResponseField>
    <ResponseField name="entrypoint" type="string | null">
      Entry point that triggered the session.
    </ResponseField>
    <ResponseField name="title" type="string | null">
      Title of the session.
    </ResponseField>
    <ResponseField name="started_at" type="string">
      ISO 8601 timestamp of when the session started.
    </ResponseField>
    <ResponseField name="ended_at" type="string | null">
      ISO 8601 timestamp of when the session ended.
    </ResponseField>
    <ResponseField name="duration_seconds" type="integer">
      Total duration of the session in seconds.
    </ResponseField>
    <ResponseField name="last_event_sequence" type="integer">
      Sequence number of the last event in the session.
    </ResponseField>
    <ResponseField name="metadata" type="object">
      Additional metadata associated with the session.
    </ResponseField>
  </Expandable>
</ResponseField>
