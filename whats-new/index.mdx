## Latest highlights

### Agent Sessions API

Start and manage multi-turn agent sessions programmatically. Sessions can span voice, chat, WhatsApp, Telegram, Slack, and web channels. Each session takes a client-generated UUID v4 so launches are idempotent by design.

[Sessions concept](/concepts/sessions) · [API Reference](/api-reference/introduction)

### MCP Server

Give your AI coding assistant direct read/write access to your Cozmo org without leaving your IDE. Works with Claude Code, Cursor, Windsurf, and VS Code Copilot. Three tool tiers (read, write, destructive) keep blast radius under control.

[MCP Server docs](/mcp/overview)

### Agent Skills

Six installable instruction sets that turn any AI coding assistant into a Cozmo expert: API Operator, MCP Toolsmith, Session Runner, Call Quality Analyst, Agent Design Reviewer, and Tenant Isolation Auditor. One command to install, zero hallucinated endpoints.

[Agent Skills overview](/skills/overview)

### Session Webhooks

`session.completed` and `session.failed` join the existing `call.completed` and `call.failed` events. All four event types use HMAC-SHA256 signing via `X-Cozmo-Signature`.

[Webhook events](/webhooks)

### Python and TypeScript SDKs

Auto-generated from the OpenAPI spec via Stainless. Both SDKs cover agents, sessions, calls, voices, workflows, and workflow runs with full type coverage, automatic retries, and pagination helpers.

[SDK overview](/sdk/overview)
